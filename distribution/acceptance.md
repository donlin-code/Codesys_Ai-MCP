# v0.1.0 验证范围

本项目是实验 SP20 Scripting API 适配器，不是官方 SP22 MCP。发布时的本地自动化结果另见 `VALIDATION.json`。

此前在独立 SP20 Patch 6 工程副本中实际验证过 MCP 初始化、工程树、ST 读取、替换、基线冲突拒绝、新建对象、独立方法、ST Action、逐项回读和完整编译；故意语法错误被报告，恢复后编译通过。保存关闭重开在独立原生 Scripting 测试中验证，与单次 MCP 写入、编译分开记录。

这些是本机历史验证结论；原始证据留在开发工作区，发行包不包含这些工程或原始会话资料。它们不证明其他电脑已经连接，也不证明当前 IDE 会话在线。每次接入应重新验证工程身份、对象读取和测试副本读写闭环。

未完成：SP22 官方插件安装/许可/真实连接、完整 v0.1 行为验收、轴与气缸运动回归、InoProShop/Motion Expert 实机适配、运行控制与现场 I/O 验证。编译、保存重开和运行行为分别判断。

发布包不含现场工程、工程分析、原框架源码、CODESYS 安装器、Node.js、开发依赖、IPC/bootstrap/session 文件或凭据。smoke 示例是准备材料，导入新工程后需用户重新编译验证。
